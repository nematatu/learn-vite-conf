# 品質検証票

現在の状態：30分解析未実行。元動画照合・公開前レビューともに未実施です。下記は検証手順であり、実施結果ではありません。

## レビューの進め方

1. 生レスポンスのHTTP、エラー、終了理由、出力の末尾を確認します。`STOP`でも内容上の欠落や入力動画へのアクセス失敗の申告があれば、資料として成功としません。
2. 冒頭、登壇者の切り替わり、30分の終端を映像で確認し、話者・タイトル・部分登壇の範囲を記録します。
3. 重要なスライド、コード/API、デモ、数値の各場面から実在する箇所を選び、元映像の文字・音声と照合します。存在しない種類は「対象なし」、確認できないものは「未照合」にします。
4. 図の要素・矢印、コードの引数・型・設定、数値の単位・条件、例示と実測、将来計画と正式提供を確認します。
5. 主要な話題と理由を保持しているかを確認します。一般知識だけで埋められた記述は、映像根拠のある解析と区別します。
6. 引用・コードの長さと出典を確認します。独自解説を中心にし、長い転載の公開は避けます。公開可能性が確認できない箇所は留保します。

## 実施時に記録する項目

| 項目 | 記録内容 |
| --- | --- |
| 実行ID / requestSha256 | メタデータから転記 |
| 確認日・確認者・方法 | 人による再生、公式資料確認など |
| ノートの見出し・主張 | 何を検証したか |
| YouTube全体の時刻・URL | 実際に確認した時刻のみ |
| 根拠 | 映像／音声／両方／外部の公式資料／補足 |
| 結果 | 一致／修正済み／未照合／不明／対象なし |
| 修正と残る制約 | 重要な情報を省略せず説明 |
