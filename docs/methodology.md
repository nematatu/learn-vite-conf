# 解析方法

## 手法 static-video-metadata-v1

2026-10-17に公式仕様を確認しました。[参照記録](references.md)に確認先と適用範囲を記載しています。

| 項目 | 今回の設定 |
| --- | --- |
| API | GenerateContent、v1beta、同期・非ストリーミングREST |
| モデル | Gemini 3.8 Flash (`gemini-3.8-flash`) |
| 入力 | 公開YouTube URLを `fileData.fileUri` へ直接指定 |
| 区間 | `videoMetadata.startOffset` / `endOffset`。初期設定0s〜1800s |
| 方式 | Static（公式動画ガイドの既定）。Agenticを指定するフィールド・ツールを付けません |
| 出力予算 | `maxOutputTokens: 32768`。モデル仕様上の最大値とは区別。採用理由・世代差は参照記録を参照 |
| プロンプト | `prompts/gemini-talk-analysis.md` の原文全文 |

時間区間はプロンプトだけで制限せず、動画入力のメタデータへ設定します。ただし、この実装で30分のリクエストがサービスに受理され、期待どおり処理されるかはまだ実行確認していません。利用者の20秒成功報告を出発点としています。

設定は `config/viteconf-2026.json` で管理します。実装上は指定動画・モデル・方式、最初の1800秒以内の整数秒の区間、最大32768出力トークンだけを許可します。全編や別の講演へ広げる前に、結果を評価し、対応範囲と手法の版を明示的に変更します。

## 音声と映像の統合

発言、画面上の文字、図のノード・矢印、コード、CLI、操作結果を対応付けるように求めます。英語原文の短い引用と日本語訳、技術的な理由、導入時のトレードオフも扱います。読み取れない文字や音声は補完せず不明と記録します。

公式動画ガイドによる通常のStatic処理は1秒に1フレームです。このため、瞬間的な表示、速い操作、小さい文字をすべて取得・判読できる保証はありません。高密度なコード画面は、音声が詳しく説明していなくても重要な検証対象です。今回、fps・メディア解像度の追加指定は行いません。

## 時刻と登壇者

時刻の基準はYouTube全体です。APIの区間内の相対時刻、公式スケジュールの配信予定時刻、アーカイブの時刻を混同しません。冒頭に待機時間があるか、登壇が予定からずれたかは未確認です。モデルが記したタイムスタンプも検証対象です。正確な時刻を確認できない場面へ、もっともらしい秒数のリンクを作りません。

公式予定では最初にWelcome、次にEvan You、次にChristoph Nakazawaです。実際の0〜30分にどの登壇が含まれるかは映像で識別します。30分の全内容を単一話者へ帰属させません。

## 正常性と正確性を分けます

送信はcurlの1回のみです。接続や出力が途切れた場合、追加通信を行いません。HTTP、curl終了状態、APIエラー、候補数、終了理由、空本文を機械的に検査します。`STOP`以外は完全な応答としてノートへ出力しません。再送は利用者が記録を確認して明示的に実行します。

機械検査を通過しても、幻覚、聞き違い、文字の誤読、例示と実測の混同、正式提供と将来計画の混同、一般知識だけによる回答は残り得ます。`verification.transport: complete_response` はAPI応答の条件のみです。生成時は `videoCrossCheck: not_performed`、`publicationReview: pending` と記録します。本文にある「確認済み」はAIの自己申告であることを先頭にも明記します。

人による確認は[品質検証票](quality-review.md)に記録します。映像・音声・外部の公式資料・補足・不明を分け、重要なコード、数値、API、話者境界を照合します。映像を確認できなかった項目は「未照合」とします。短いノートへの再要約で技術情報を削りません。

## 再現性と変更管理

各実行で送信JSON、設定、プロンプトを `.local/runs/` に複製します。公開用メタデータに日時（UTC）、条件、リクエストとプロンプトのSHA-256、数値の使用量を保存します。欠落した使用量は0で埋めず `null` とします。`VIDEO`のトークン内訳は音声等を含む総入力とは分けます。認証情報、生レスポンス、思考情報は公開対象に含めません。

モデル、方式、区間、出力設定を変更したら、設定・生成JSON・手法バージョン・公式仕様の確認日をGitの同じ変更で更新します。ノートのメタデータには実行時の条件が残ります。将来 `videoMetadata` から移行する際も、対応仕様と同一区間の結果を比較してから変更します。現時点で移行後の挙動は未確認です。
