# プロジェクトの目的と範囲

ViteConf 2026の技術情報を、映像・音声の対応が分かる日本語Markdownとして蓄積します。対象読者はReact、TypeScript、Viteなどの開発経験がある方です。API、設計判断、実装、図表、ベンチマークの条件、デモの挙動を具体的に記録し、将来NotebookLMなどの学習ソースとして再利用できる資料を目指します。

今回の範囲は、既存の公開リポジトリ `nematatu/learn-vite-conf` に生成手順を実装し、指定モデル `gemini-3.8-flash` とGenerateContent APIで0〜1800秒を1回解析することです。リポジトリの新規作成・改名は行いません。

新しいアプリ、UI、インフラ、NotebookLMの操作、全編の一括処理、Agentic、Interactions API、有料プランや請求設定の変更は範囲外です。

## 完了を分けて記録します

1. **実装**：原文プロンプト、設定、リクエスト、送信・抽出手順があり、オフライン検証が通ること。
2. **API実行**：利用者のキーで1リクエストを送信し、実際のHTTP・終了理由・トークン数を保存すること。
3. **学習資料**：具体的な技術内容があり、映像の照合結果・不明点が示され、引用範囲を確認して公開されること。

APIキーがない状態では2・3を完了扱いにしません。登壇者や登壇境界が確定できなければ登壇別レポートを無理に作成しません。
